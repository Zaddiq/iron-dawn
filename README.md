# Iron Dawn (working title)

A man-vs-machine hex strategy game for a host tablet and phone players: a giant walking war machine attacks a dug-in human force.
Original game, original names and wording. Work in progress.

Starting files copied from the owner's Colosseum project: `net.js` (table transport), `voice.js` (voice chat),
`firebase-config.js`, `database.rules.json`, `phone-map.js` (hex map on the phone).

Next: a small first scenario (one machine, about a dozen defenders, small ruined-city map), tablet host plus one phone.
